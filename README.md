# What Is Art? 🎨🤖

A mobile-first web application that challenges users to distinguish between human-created masterpieces and AI-generated imitations.

## 🌟 Concept

In an age where AI can mimic the styles of Van Gogh or Monet, "What Is Art?" asks the ultimate question: **Can you tell the difference?**

Users are presented with a series of paintings. Some are genuine historical artifacts; others are hallucinations of a machine. The goal is to swipe your way to the truth.

## 🎮 Features

-   **Swipe Interface**: Intuitive Tinder-style mechanics. Swipe **Right** for Real Art, **Left** for AI.
-   **Immediate Feedback**: Instant visual cues (Green/Red) and reveal overlays showing the artwork's origin.
-   **Progress Tracking**: glitched-themed progress bar tracking your journey through the gallery.
-   **Personality Archetypes**: Your final score isn't just a number. It unlocks one of **10 unique personalities**, ranging from "The Robot's Pet" to "The Visionary."
-   **Social Sharing**: Share your archetype and score directly to WhatsApp or copy the link to challenge friends.
-   **Premium Design**: A dark, cinematic aesthetic featuring glassmorphism, smooth physics-based animations, and a responsive layout.

## 🛠 Tech Stack

-   **Core**: React 18 + Vite
-   **Styling**: Vanilla CSS with comprehensive CSS Variables implementation for theming.
-   **Design System**: Custom "Glass" aesthetic with high-contrast typography (Inter).
-   **Assets**: Curated set of Real vs. AI images.

## 🚀 Getting Started

### Prerequisites

-   Node.js (v16+)
-   npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/kardelly/whatisart.git
    cd whatisart
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📱 Mobile Optimized

This application is designed with a "mobile-first" approach, ensuring the swipe gestures and layout feel native on touch devices while scaling gracefully to desktop screens.
